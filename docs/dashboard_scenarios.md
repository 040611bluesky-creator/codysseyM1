# 대시보드 스크린샷 시나리오

배포가 어려울 때 제출할 화면 캡처를 준비하는 안내입니다. 먼저 프로젝트 폴더에서 `streamlit run app.py`를 실행하고 브라우저에서 대시보드를 엽니다. 각 시나리오마다 조건을 바꾼 뒤 화면을 캡처해 `images/`에 저장합니다.

## 시나리오 1: 평일만 보기

1. 기간은 전체 기간으로 둡니다.
2. 요일 선택에서 월요일~금요일만 남깁니다.
3. 지표는 총 이용객, 이동평균은 30일, 이상치 기준은 30%로 둡니다.

캡처할 화면:

- 평일 조건이 보이는 사이드바와 요약 카드
- 일별 추세와 이동평균 그래프
- 요일별 평균 그래프

## 시나리오 2: 2025년 1월 명절 구간 살펴보기

1. 기간을 2025-01-27부터 2025-01-30까지로 설정합니다.
2. 요일은 전체를 선택합니다.
3. 지표는 총 이용객, 이동평균은 30일, 이상치 기준은 30%로 둡니다.

캡처할 화면:

- 선택한 날짜 범위가 보이는 사이드바와 요약 카드
- 해당 기간의 일별 추세 그래프
- 이상치 표의 날짜, 요일, 이용객, 같은 요일 평균 대비 비율

## 시나리오 3: 7일 이동평균으로 짧은 흐름 보기

1. 기간은 전체 기간으로 둡니다.
2. 지표는 총 이용객, 요일은 전체, 이상치 기준은 30%로 둡니다.
3. 이동평균 일수를 7일로 바꿉니다.

캡처할 화면:

- 이동평균이 7일로 설정된 사이드바와 요약 카드
- 7일 이동평균 선이 보이는 일별 추세 그래프
- 요일별 평균과 월별 일평균 그래프
